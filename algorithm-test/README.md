# Algorithm Test — findMaxInMin

Given an array and a number `k`, take every consecutive subset of length `k`, find the minimum of each subset, then return the largest of those minimums.

Example: `[8,1,6,3,66,1,8,5]`, `k = 3` returns `3`.
